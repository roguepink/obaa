# 最強おばあ 〜杖でこらしめ道中〜

https://roguepink.github.io/obaa/

縦にずっと進む道で、最強のおばあが杖と投げる物で悪者をこらしめるゲーム。全100ステージ。
小石・空き缶・バナナの皮につまずくと終わり。

- 操作: 指で左右になぞる / ジャンプ(2回で二段ジャンプ)/ 杖(押しっぱなしで物を投げる)/ 必殺(10種からランダム)
- モード: かんたん(3回までOK)/ ふつう / むずかしい。行ったステージから「つづきから」遊べる
- ステージ: 場所25種 × 悪者25種 × 登場回数(ふつう・メカ・巨大・真)= 100。100面は「悪の大黒幕」
- 投げる物10種: みかん・せんべい・おにぎり・入れ歯・毛糸玉・湯のみ・スイカ・ぞうり・飴玉・だんご(🎁で変わる)

## ファイル
- `index.html` 画面の部品  / `js/data.js` 場所・悪者・投げる物・必殺技・ステージの組み立て / `js/game.js` ゲームの動き
